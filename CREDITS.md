# Credits — TESL Forge

TESL Forge is made by **ArchAngelAries**, built with AI coding assistants (Claude by Anthropic).

## The original game
- ***The Elder Scrolls: Legends*** — developed by **Dire Wolf Digital** and later **Sparkypants Studios**, published by
  **Bethesda Softworks** (ZeniMax Media). All game content belongs to them.

## Data and research
- **crow2cr0w** — [tesl-offline](https://github.com/crow2cr0w/tesl-offline): the original card rule data that TESL Forge's
  card catalog and rule editor read (shipped with TESL: Everlasting).
- **The UESP editors** — [UESP Legends pages](https://en.uesp.net/wiki/Legends:Legends) (CC BY-SA 2.5).
- **TESL-Reborn** — for a reference installation that helped check rules and data. Separate project, not affiliated.

## Libraries and tools
- [UnityPy](https://github.com/K0lb3/UnityPy), [texture2ddecoder](https://github.com/K0lb3/texture2ddecoder),
  [etcpak](https://github.com/K0lb3/etcpak), [astc-encoder-py](https://github.com/K0lb3/astc-encoder-py),
  [fmod_toolkit](https://github.com/K0lb3/fmod_toolkit) by **K0lb3** — the reason reading Unity games is possible at all.
- [Pillow](https://python-pillow.org/), [lz4](https://github.com/python-lz4/python-lz4),
  [brotli](https://github.com/google/brotli), [fsspec](https://github.com/fsspec/filesystem_spec),
  [attrs](https://github.com/python-attrs/attrs), [archspec](https://github.com/archspec/archspec),
  [pyfmodex](https://github.com/tyrylu/pyfmodex), [Python](https://www.python.org/).
- **FMOD Studio** by Firelight Technologies Pty Ltd — audio decoding, when installed (not bundled; see `NOTICE.md`).
- Optional: [ffmpeg](https://ffmpeg.org/), [Blender](https://www.blender.org/).
